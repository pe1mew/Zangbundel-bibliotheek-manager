## How

- **A real cycle through the interface.** One script, the same for both browsers, clicked through the manager's own buttons and dialogs, in Dutch at 1400 × 900. A test hook in the page stood in for two things:
  - the file picker, which received the public test library and later the downloaded files;
  - the browser's save step: the downloaded bytes were taken from the `blob:` URL the manager made, so nothing was written to disk.
- **The key presses were real:**
  - Edge: Chrome DevTools Protocol `Input.dispatchKeyEvent`.
  - Firefox: WebDriver BiDi `input.performActions`.
- **The CSP:** the server sent the production CSP, except `connect-src 'self'` in place of `'none'`, which the test hook needed to fetch the test library.
- **Two corrections to the script itself before the final runs:**
  - It clicked *Sleutel laden* while the bottom bar was still busy after an open.
  - It had left the download confirmation open, which held the focus.

  Both were the script's faults, not the manager's.

## Rerunning it

The check is in the repository: `webapp/tests/browsers/` (`drive.mjs`, `cycle.js`, `serve.py`).
- **Command:** `node webapp/tests/browsers/drive.mjs all dist/manager-<version>`.
- **What it does:** it starts its own server with the CSP read from `conf.d/zangbundel.conf`, runs both browsers, prints a line per step, and exits 1 on any failure.
- **The repository version** passed 14 of 14 steps in both browsers on dev.5.
- **It fails when it should:** against `manager-0.2.1` it failed, with exit 1, on the missing button key and the missing F1 help.

## Not covered

- **Safari:** it runs only on macOS, so it was not tested. TD-15 lists it; it needs someone with a Mac.
- **The browsers' own download handling:** where the file is saved, and the browser's download prompt. Testers on the test instance cover this with normal use.
- **The test instance itself:** the run used the same build on a local server, because the test instance needs the tester login.
- **Chromium (Chrome)** was covered earlier in the browser pane (release gate of 0.2.0, the dry run of 0.3.0).
