Privacy statement

This statement covers zangbundel.nl and test.zangbundel.nl. Last changed: 6 November 2026.

Who

This website is run by Remko Welling (PE1MEW). Questions and requests go through the project's issues on GitHub.

What this website does

For now there is only this information page. Later the library manager will run here. It processes your song library and your signing key only in your own browser: they are never sent to this server or to anyone else.

Server logs

For each visit the server records: your IP address shortened (the last part removed, so it no longer points to one connection), the time, the page requested, the status code and the size of the answer. Your browser details are not kept. This serves only to keep the website secure and to find faults (legitimate interest, Article 6(1)(f) GDPR). The logs are deleted after 14 days. Only when something goes wrong on the server, or when someone signs in to test.zangbundel.nl with an unknown user name or a wrong password, does a message with the full IP address (and, for a sign-in, the user name entered) go into a separate error log; that is deleted after 14 days too.

Cookies and storage

This website uses no cookies, no visitor statistics and no services of others. This page stores nothing in your browser. The library manager will later keep only your language and the width of the side bars in your browser, on your own computer.

Links to other websites

Links to GitHub, Google Play and F-Droid open websites with their own privacy policies. This website does not tell them which page you came from.

Your rights

You have the right to access, correct and erase data about you. Because IP addresses are stored shortened, we usually cannot find you in the logs. If you disagree with how we handle data, you can complain to the Dutch data protection authority, the Autoriteit Persoonsgegevens.
