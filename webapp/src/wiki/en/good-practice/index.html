Manual

Good practice

Keep your library file

The manager keeps nothing: when you close the page, your work is gone. So download the library when you are done, and keep that file in a fixed place. Next time, open that very file and go on. The last file you downloaded is your original.

Song IDs

Each song gets a song ID on Apply, proposed from its title. After that it never changes, not even when you change the title, because setlists in the app refer to it. So give a new song a good title from the start.

Titles

Give each song the title singers know it by. Two songs with the same title and language give a warning. If a song exists in two languages, give each version its own language; otherwise a subtitle helps.

Tags

Tags let you filter songs in the app, for example campfire, cubs or christmas. Use a few that your group really uses, always the same way: lower-case letters, digits and hyphens, separated by commas.

Sets

A set is a setlist for an occasion, such as a campfire or an opening. A song can be in several sets. Deleting a set, or taking a song out of a set, does not delete the song itself. An empty set gives a warning.

Versions

Every download gives the library a higher version number. The app knows the library by its own ID: a higher version with the same key replaces the previous one without asking. With the same or a lower version, or another key, the app asks first. Save as copy, in the Download dialog, makes a new library, with a new ID and version 1: the app sees it as a different library.

Keys

  • One key per maker is enough; use it for all your libraries.
  • Keep the key file in a safe place, not in a shared folder and not on a shared computer. Make a backup, for example on a USB stick.
  • Never send your key file to anyone. The makers of the manager never ask for it.
  • A signed library opens read only. Load your key to change it.
  • Lost, or in the wrong hands? Go on with Save as copy and sign the copy with a new key. Tell the people who use it that the copy is the new one.

Sharing

Share the downloaded file any way you like: by mail, in a chat, on a website or on a USB stick. On import, the app checks it with the same rules as the manager.
