## Bewahre deine Bibliotheksdatei auf {#keep-file}

Die Verwaltung speichert nichts: Wenn du die Seite schließt, ist deine Arbeit weg. Lade die Bibliothek also herunter, wenn du fertig bist, und bewahre diese Datei an einem festen Ort auf. Beim nächsten Mal öffnest du genau diese Datei und machst weiter. Die zuletzt heruntergeladene Datei ist dein Original.

## Lied-IDs {#song-ids}

Jedes Lied bekommt beim **Übernehmen** eine Lied-ID, vorgeschlagen aus dem Titel. Danach ändert sie sich nicht mehr, auch nicht, wenn du den Titel änderst, denn Setlisten in der App verweisen darauf. Gib einem neuen Lied deshalb gleich einen guten Titel.

## Titel {#titles}

Gib jedem Lied den Titel, unter dem Sänger es kennen. Zwei Lieder mit demselben Titel und derselben Sprache ergeben eine Warnung. Gibt es ein Lied in zwei Sprachen, gib jeder Fassung ihre Sprache; sonst hilft ein Untertitel.

## Tags {#tags}

Mit Tags filterst du Lieder in der App, zum Beispiel `lagerfeuer`, `woelflinge` oder `weihnachten`. Verwende einige, die deine Gruppe wirklich nutzt, immer gleich: Kleinbuchstaben, Ziffern und Bindestriche, durch Kommas getrennt.

## Sets {#sets}

Ein Set ist eine Setliste für einen Anlass, etwa ein Lagerfeuer oder eine Eröffnung. Ein Lied kann in mehreren Sets stehen. Ein Set zu löschen oder ein Lied aus einem Set zu nehmen, löscht das Lied selbst nicht. Ein leeres Set ergibt eine Warnung.

## Versionen {#versions}

Bei jedem Herunterladen bekommt die Bibliothek eine höhere Versionsnummer. Die App erkennt die Bibliothek an ihrer eigenen ID: Eine höhere Version mit demselben Schlüssel ersetzt die vorige ohne Nachfrage. Bei derselben oder einer niedrigeren Version oder einem anderen Schlüssel fragt die App zuerst. **Als Kopie speichern**, im Fenster von **Herunterladen**, macht eine neue Bibliothek, mit neuer ID und Version 1: Die App sieht sie als eine andere Bibliothek.

## Schlüssel {#keys}

- Ein Schlüssel pro Person reicht; verwende ihn für alle deine Bibliotheken.
- Bewahre die Schlüsseldatei an einem sicheren Ort auf, nicht in einem geteilten Ordner und nicht auf einem geteilten Computer. Mach eine Sicherungskopie, zum Beispiel auf einem USB-Stick.
- Schicke deine Schlüsseldatei niemals an jemanden. Die Macher der Verwaltung fragen nie danach.
- Eine signierte Bibliothek öffnet sich **nur zum Lesen**. Lade deinen Schlüssel, um sie zu ändern.
- Verloren oder in falschen Händen? Mach mit **Als Kopie speichern** weiter und signiere die Kopie mit einem neuen Schlüssel. Sag den Leuten, die sie nutzen, dass die Kopie die neue ist.

## Teilen {#sharing}

Teile die heruntergeladene Datei, wie du willst: per Mail, in einem Chat, auf einer Website oder per USB-Stick. Beim Import prüft die App sie mit denselben Regeln wie die Verwaltung.
